Full Featured E-Commerce WebApp
A comprehensive e-commerce platform prototype built to simulate real world online shopping experiences, including product catalogs, category filtering, and shopping cart functionality.

Features
Interactive product listing with categories and detail views

Dynamic cart management for adding and removing items

Modern responsive layout designed for mobile and desktop screens

Tech Stack
HTML5

CSS3

JavaScript

Getting Started
Clone the repository: git clone https://github.com/avto2006/Full-Featured-E-Commerce-WebApp.git

Open index.html in your browser or run a local server
